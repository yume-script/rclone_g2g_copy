속도 설정 — 서버사이드 복사가 느리게 느껴진다면 아래 값을 올려보세요. 파일마다 독립적인 API 호출이라, 동시에 더 많이 보낼수록 체감 속도가 크게 빨라지는 경우가 많습니다.

rclone --transfers 값입니다. 기본값(rclone 자체 기본은 4)보다 높은 8을 기본으로 씁니다. 너무 높이면 구글 API 레이트리밋(오류 403)에 걸려 오히려 느려질 수 있으니, 16~32 정도까지만 천천히 올려보는 걸 권장합니다.

rclone --checkers 값입니다. 파일 존재 여부/목록을 확인하는 동시 개수로, 전송(TRANSFERS)보다 보통 더 높게 잡습니다.

rclone --fast-list 옵션입니다. 폴더 목록을 API 호출 한 번에 최대한 많이 가져와서, 목록 조회에 걸리는 API 호출 수 자체를 줄여줍니다 (파일 개수가 많은 폴더를 복사할 때 특히 효과적).
